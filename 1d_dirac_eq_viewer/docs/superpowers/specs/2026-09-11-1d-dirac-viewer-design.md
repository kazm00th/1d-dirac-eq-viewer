## 1. 目的とスコープ

1+1次元ディラック方程式の時間発展を、ブラウザ上でリアルタイムに可視化・操作するツールを作る。
学習者が質量・初期分枝・外場を手で動かし、相対論的量子力学の非直感的な現象を目で追えるようにする。

### 1.1 主題とする現象

| 現象 | 必要なもの |
|---|---|
| Zitterbewegung（振動数 `2E_k`） | 正負分枝の重ね合わせ。質量が必要 |
| 群速度の光速への飽和（`v_g = k/E → c`） | 分散関係の正確さ |
| 負分枝の逆進（運動量と逆向きに進む） | 分枝を指定した初期条件 |
| 質量ゼロ極限での左右分離 | `m = 0` |
| Klein パラドックス | 静電ポテンシャル `V(x)` |
| 静電とスカラーの対比（同じ壁でも `V` は透過し `S` は反射） | `V(x)` と `S(x)` の両方 |

### 1.2 スコープに含まない

- 可聴化（音）
- 学習シナリオ、ガイド付きツアー、理解確認の設問
- 共有 URL、状態のシリアライズ
- データ書き出し
- 時間依存ベクトルポテンシャル `A(x,t)`
- モバイル最適化

### 1.3 既存資料との関係

`1d_dirac_eq_learning/requirements.md`（可視化・可聴化アプリ v1.2）とは**独立**の成果物とする。

## 2. 対象方程式と単位系

### 2.1 方程式

```
i ∂ψ/∂t = [ -i c α ∂/∂x  +  β (m c² + S(x))  +  V(x) ] ψ,     ψ = (ψ₁, ψ₂)ᵀ
```

- `ψ` は 2成分スピノル（1+1次元なのでスピン自由度はない）
- `V(x)`: 静電ポテンシャル。両成分に等しく加わる
- `S(x)`: スカラーポテンシャル。質量項に加わる（実効質量 `m + S(x)`）

### 2.2 表現

**Weyl 表現**を採用する。

```
α = σ_z = [[1, 0], [0, -1]]
β = σ_x = [[0, 1], [1,  0]]
```

Clifford 条件 `α² = β² = I`, `{α, β} = 0` を満たす。

この取り方の利点:

1. **運動項が成分について対角になる。** 成分ごとの方程式は
   ```
   ∂ψ₁/∂t = -c ∂ψ₁/∂x + (質量・外場項)
   ∂ψ₂/∂t = +c ∂ψ₂/∂x + (質量・外場項)
   ```
   `m = S = V = 0` なら `ψ₁(x - ct)`（右進行）、`ψ₂(x + ct)`（左進行）に完全分離する。
   質量とスカラー場だけが左右を結合する。

2. **確率密度とカレントが単純になる。**
   ```
   ρ = |ψ₁|² + |ψ₂|²
   j = c (|ψ₁|² - |ψ₂|²)
   ```
   `j = c ψ†σ_z ψ` がそのまま2成分の密度差になる。`|j| ≤ c ρ` が恒等的に成立し、
   確率の流れが `c` を超えないことが式の形から直接読める。

Dirac 表現 `α = σ_x, β = σ_z` では運動項が非対角になり、上の 1 が使えない。
またカレントが `j = 2c Re(ψ₁*ψ₂)` という干渉項の形になり、2 の直感も失われる。

### 2.3 単位系

`ħ = c = 1`。長さの単位は `m = 1` のときの**換算**コンプトン波長 `ƛ_C = ħ/(mc)`。

UI には `ƛ_C` と明記する。コンプトン波長 `λ_C = h/(mc) = 2π ƛ_C` とは `2π` 違うため、
「コンプトン波長」とだけ書いてはならない。

Zitterbewegung の周期は `π/m`（振動数 `2mc²/ħ = 2m`）。`m = 1` なら周期 `π ≈ 3.14` 時間単位。

## 3. 数値解法

### 3.1 格子

| 量 | 値 | 備考 |
|---|---|---|
| `N` | 512 | FFT のため 2 の冪に固定 |
| `L` | 40 `ƛ_C` | 周期境界 |
| `h` | `L/N ≈ 0.078` | |
| `x_j` | `j h`, `j = 0 … N-1` | |
| `k_n` | `2π n / L`, `n = -N/2 … N/2-1` | FFT の並び順に従って格納 |
| `Δt` | 0.002 | 固定の副ステップ幅 |

**CFL 制限はない。** 運動ステップは `k` 空間の厳密な位相回転であり、有限差分のような
安定性の制約を受けない。`Δt` を制限するのは Strang 分割の精度のみ。
`Δt` を上げても発散はせず、精度が落ちるだけである。

### 3.2 Strang 分割による 1 副ステップ

```
1. 実空間で V/S を Δt/2 進める        -- 2×2 の厳密な行列指数
2. FFT (ψ₁, ψ₂ それぞれ)
3. k 空間で位相回転  ψ̂₁ *= e^(-i k Δt),  ψ̂₂ *= e^(+i k Δt)
4. 逆 FFT
5. 実空間で V/S を Δt/2 進める
6. 吸収マスク M(x) を掛け、減ったノルムを積算する
```

ステップ 1・5 と 3 はいずれも厳密。誤差源は Strang 分割のみで、大域的に `O(Δt²)`。
吸収を切れば全体が厳密にユニタリになり、ノルムが機械精度で保存する。

**ステップ 3 の符号**: `ψ₁ ~ e^(ikx)` に対し `i ∂ψ̂₁/∂t = -i c (ik) ψ̂₁ = c k ψ̂₁` より
`ψ̂₁(t+Δt) = e^(-ikΔt) ψ̂₁(t)`。`ψ₂` は符号が逆になる。

### 3.3 ポテンシャル・質量ステップの厳密形

`M(x) = V(x) I + (m + S(x)) σ_x` の指数は閉じた形で書ける:

```
exp(-i Δt M) = e^(-i V Δt) [ cos((m+S)Δt) I  -  i sin((m+S)Δt) σ_x ]
```

具体的には、各格子点で `a = ψ₁`, `b = ψ₂`（複素）に対し

```
c_ = cos((m + S_j) dt)
s_ = sin((m + S_j) dt)
a' = c_ a - i s_ b
b' = c_ b - i s_ a
（さらに全体に e^(-i V_j dt) を掛ける）
```

近似は入らない。1 格子点あたり数十 flop。

### 3.4 吸収層

両端に幅 `W` の滑らかな `cos²` テーパーによる実数マスク窓を置く。

```
M(x) = 1                                     （中央部）
M(x) = cos²( (π/2) · (W - d)/W )             （端から距離 d < W の領域）
```

無反射ではないが、`W ≳ 5 ƛ_C` 取れば実用上問題ない。
吸収した確率量は累積して常時数値表示する（消えた確率を隠さない）。
`W = 0` で吸収オフ、このとき時間発展は完全にユニタリになる。

将来この方式を複素吸収ポテンシャルやスカラー質量ランプに変更する場合は、
**質量ゼロで推奨が逆転する**（電磁型が無反射、スカラー型が全反射になる）ことに注意すること。
実数マスク窓はこの罠を踏まない。

### 3.5 分枝スピノル

自由ハミルトニアン `H₀(k) = k σ_z + m σ_x = [[k, m], [m, -k]]` の固有ベクトル
（固有値 `±E_k`, `E_k = √(k² + m²)`）:

```
u₊(k) = (1/√(2 E_k (E_k + k))) · ( E_k + k ,   m        )ᵀ
u₋(k) = (1/√(2 E_k (E_k + k))) · ( m        , -(E_k + k) )ᵀ
```

直交性 `u₊† u₋ = 0` は `(E_k+k)·m + m·(-(E_k+k)) = 0` から直ちに従う。

**桁落ちの回避（必須）**: `m → 0` かつ `k < 0` では `E_k + k → 0` となり、規格化因子が
`0/0` に落ちて NaN が全域へ伝播する。等価な別形

```
u₊(k) ∝ ( m , E_k - k )ᵀ
```

を併せ持ち、`|E_k + k|` と `|E_k - k|` の大きい方を使う分岐を入れる。
`m = 0` ちょうどでは `u₊ = (1,0)ᵀ`（`k > 0`）/ `(0,1)ᵀ`（`k < 0`）に落ちる。
`m` スライダーの下端が 0 である以上、この経路は必ず通る。

### 3.6 `⟨H⟩` の評価

`H = c α p + β(m + S) + V` の 3 項を、それぞれ評価しやすい空間で計算して足す。

**前提**: `fft.js` は Parseval の等式が成り立つ規格化を保証すること
（`h Σ_j |ψ_j|² = Σ_n |ψ̂_n|²`）。以下の式はこの規格化の下で書く。

```
運動項（k 空間）    T = Σ_n k_n ( |ψ̂₁(k_n)|² - |ψ̂₂(k_n)|² )
質量・スカラー項     M = h Σ_j (m + S_j) · 2 Re( ψ₁,j* ψ₂,j )
静電項              U = h Σ_j V_j ρ_j

⟨H⟩ = (T + M + U) / ノルム
```

運動項が `k` 空間で成分ごとの差になるのは `α = σ_z` が対角だからで、
質量項が `2 Re(ψ₁* ψ₂)` になるのは `β = σ_x` が非対角だから。
Weyl 表現を選んだ帰結がそのまま式の形に出ている。

### 3.7 手描き外場の平滑化

`k` 空間でのガウシアン畳み込みで実装する（FFT を再利用するため追加コードはほぼ不要）。

```
V ← IFFT( FFT(V) · exp(-σ_s² k² / 2) ),   σ_s = 2h
```

- 「平滑化」ボタン1つ。選択中の場（`V` か `S`）にのみ作用する
- 1 回押すごとに 1 パス適用。連打すると合成幅は `√n · σ_s` で増える
- 停止中のみ有効。プリセットの階段にも適用できる
- 周期境界のため畳み込みは `x=0` と `x=L` をまたいで回り込む。ソルバ自体が周期境界である以上
  これは整合的な挙動であり、バグではない

平滑化は見た目の問題だけではない。手描きのギザギザは高 `k` 成分を大量に含み、
Strang 分割の誤差を押し上げる。平滑化は数値精度そのものを改善する操作でもある。

## 5. 可視化

### 5.1 レイアウト

参照実装の縦 1 カラム構成を踏襲する。キャンバスは 2 枚。

```
┌─ タイトル + 方程式 ────────────────────────────────┐
├─ 表示切替（群化したチェックボックス）   数値タイル列 ─┤
├─ [Y軸] ┃ 実空間キャンバス   x — ρ, ψ₁, ψ₂, j, V, S  ┃ ┤
├─ ヒント行 ─────────────────────────────────────────┤
├─        ┃ 運動量キャンバス   k — 分散関係 ＋ 分枝の重み ┃ ┤
├─ スライダー群 ─────────────────────────────────────┤
├─ 開始 / 停止 / リセット ───────────────────────────┤
├─ 初期状態プリセット ───────────────────────────────┤
├─ 外場プリセット ＋ 場の選択(V/S) ＋ 平滑化 ────────┤
└────────────────────────────────────────────────────┘
```

### 5.2 実空間キャンバス

チェックボックスは 4 群に畳む。既定は最小限にして、増やすのは学習者に任せる。

| 群 | 要素 | 既定 |
|---|---|---|
| 密度 | `ρ = \|ψ₁\|² + \|ψ₂\|²` | オン |
| 成分 | `\|ψ₁\|`（右進行）, `\|ψ₂\|`（左進行） | オフ |
| 実部・虚部 | `Re ψ₁`, `Im ψ₁`, `Re ψ₂`, `Im ψ₂` | オフ |
| 流れ | `j = c(\|ψ₁\|² - \|ψ₂\|²)` | オフ |
| 外場 | `V(x)`（点線）, `S(x)`（破線・別色） | オン |

吸収層の領域は背景を淡く塗って区別する。「端で消えるのは物理ではなく吸収層である」ことを
見た目で分からせるため。

### 5.3 運動量キャンバス

横軸 `k`、縦軸 `E` の平面に次の 3 つを重ねる。

1. 分散関係の 2 本の分枝 `E = ±√(k² + m²)`（実線）
2. 光速の漸近線 `E = ±k`（点線）
3. 現在の状態の重み `|w₊(k)|²`, `|w₋(k)|²` を、対応する曲線上の線幅または濃度として乗せる

この 1 枚で次が同時に見える:

- 質量ギャップ `2m` が開いていること。`m` を 0 に落とすとギャップが閉じ、2 本の分枝が
  漸近線に重なって直線になる
- 曲線の傾き `dE/dk = k/E → ±1`。`k` を上げても傾きが 1 を超えないこと（群速度の飽和）
- 状態が正負どちらの分枝にどれだけ乗っているか

`|ψ̂(k)|²` の棒グラフにしないのは、`k` だけの分布では分枝の情報が落ちるため。
同じ `k` に正負 2 つの状態があるのが Dirac の本質であり、平面に置いて初めて分離して見える。

### 5.4 数値タイル

| タイル | 式 |
|---|---|
| `t` | 経過時間（`ƛ_C/c` 単位） |
| ノルム | `∫ ρ dx` |
| 吸収済み | 累積した吸収量 |
| `⟨x⟩` | `∫ x ρ dx / ∫ ρ dx` |
| `⟨v⟩` | `∫ j dx / ∫ ρ dx` |
| `⟨H⟩` | `⟨ψ\|H\|ψ⟩`（`V`, `S` 込み） |
| `w₊ : w₋` | 分枝の重み比 |

`⟨v⟩` を「`⟨x⟩` の数値微分」ではなく「`j` の積分」で出すこと。前者はノイズを拾い、
吸収層で確率が減ると意味が壊れる。後者は `|⟨v⟩| ≤ c` が構造的に保証される。

吸収を切れば ノルム と `⟨H⟩` は機械精度で保存する。
「見えているものは物理であって数値誤差ではない」を学習者が自分で確認できる指標として置く。

### 5.5 分枝の重みに関する必須の注記

分枝の重みは自由ハミルトニアン `H₀(k)` の固有ベクトルへの射影で測る。
`V` や `S` が非ゼロのときこれは**保存量でも真の粒子／反粒子分解でもない**。

UI に「自由基底での射影」というラベルを常時添えること。
Klein 障壁の中で「負エネルギー成分が増えた」ように見えても、それが基底の取り方の産物である
可能性を学習者が判断できるようにするため。

## 6. 操作

参照実装の「停止中はドラッグで描画、実行中はクリックで加算」という体系を、
本ビューアでは**外場の編集**に転用する。

| 操作 | 動作 |
|---|---|
| 停止中のドラッグ | 選択中の外場（`V` / `S` をラジオで切替）を直接描く |
| 実行中 | 外場は編集不可（誤操作防止）。`m` スライダーのみ生きている |
| マウスホイール | Y 軸範囲の調整 |
| 開始 | その瞬間の状態をチェックポイントとして保存し、時間発展を開始・再開する |
| 停止 | アニメーションを止める。状態はそのまま保持され、再び編集できる |
| リセット | 直近のチェックポイントに戻し、`t = 0` とする |

### 6.1 スライダー

| スライダー | 範囲 | 備考 |
|---|---|---|
| 質量 `m` | 0 〜 3 | 実行中も動かせる |
| 時間発展の速度 | 1 〜 20 | 副ステップ数/秒。`Δt` は 0.002 固定 |
| Y 軸範囲 | 0.2 〜 4 | 縦置き |
| 吸収層の幅 `W` | 0 〜 10 `ƛ_C` | 0 で吸収オフ |
| 波束の中心 `x₀` | 0 〜 `L` | 初期条件用 |
| 波束の運動量 `k₀` | -20 〜 20 | 初期条件用 |
| 波束の幅 `σ` | 0.3 〜 5 | 初期条件用 |

`m` を実行中も変更可能にするのは意図的。Strang 分割は各ステップで `V, S, m` を読み直すだけなので、
時間依存の質量を与えても実装上は何も変わらない。
学習者が「質量を上げると Zitterbewegung が速くなり振幅が縮む」をリアルタイムに触れる。

フレームレートに依存せず物理時間の進み方を一定にするため、`performance.now()` の経過時間で
副ステップ数を積算する（参照実装と同じ方式）。1 フレームあたりの副ステップ数に上限を設け、
タブが非アクティブだった場合の暴走を防ぐ。

## 7. 初期条件

### 7.1 作り方

`k` 空間でガウス包絡を分枝スピノルに掛け、逆 FFT する。

```
ψ̂(k) = exp[ -(σ²/2)(k - k₀)² ] · e^(-i k x₀) · u_s(k)
```

これで分枝に厳密に乗った波束が作れる。

実空間でガウスを置いてから射影する方式を採ってはならない。有限領域での切り落としにより
分枝が微量に混ざり、「正分枝のみ」のはずが微小な Zitterbewegung を出す。
これは「純粋な分枝でも振動する」という誤った理解を学習者に与える。

### 7.2 プリセット

| プリセット | 中身 | 見えるもの |
|---|---|---|
| 正分枝のみ | `ψ̂ = g(k) u₊(k)` | 素直に一方向へ進む。Zitterbewegung は出ない。群速度 `k₀/E_k₀` |
| 負分枝のみ | `ψ̂ = g(k) u₋(k)` | 群速度が `-k₀/E_k₀`。運動量と逆向きに進む |
| 50:50 混合 | `g(k)[u₊(k) + u₋(k)]/√2` | Zitterbewegung が最大振幅。振動数 `2E_k₀` |
| 素朴な固定スピノル | `ψ = (g(x), 0)ᵀ` | 勝手に正負が混ざり、Zitterbewegung が出る |

4 つ目が教材としての要である。「上の成分にガウスを置く」という素朴な操作が、
望むと望まざるとに関わらず分枝混合を生む。学習者が最初にやりがちなことをそのまま実演にしてある。

`m = 0` ではこのプリセットが純粋な右進行（`k₀ > 0` なら正分枝そのもの）になり、
Zitterbewegung が消える。質量がなければ Zitterbewegung もないことが同じ操作で確認できる。

## 8. 外場

| プリセット | 形 | 見えるもの |
|---|---|---|
| なし | `V = S = 0` | 自由伝播 |
| 階段 `V` | 高さ `V₀` の静電階段 | `V₀ > E + m` で Klein パラドックス。壁の中で減衰せず透過する |
| 障壁 `V` | 有限幅の静電障壁 | Klein トンネリング。厚くしても透過率が落ちない |
| 階段 `S` | 同じ高さのスカラー階段 | Klein は起きない。実効質量が `m + S₀` に増えるだけで、`E < m + S₀` なら全反射 |
| スカラー井戸 `S` | 負のスカラー井戸 | 束縛状態 |
| 手描き | ドラッグ | 任意形状 |

`V` 階段と `S` 階段を同じ高さ・同じ形で並べられるようにすること。
見た目が同じ壁で振る舞いが正反対になるのが、静電とスカラーの違いの最も効く見せ方である。

## 9. 検証

テストフレームワークは導入しない。`tests.html` を 1 枚置き、開くと全項目を実行して合否を表示する。
実装は TDD で進める（各項目のテストを先に書き、赤を確認してから実装する）。

| # | 検証項目 | 判定基準 |
|---|---|---|
| 1 | FFT の往復 | `IFFT(FFT(x)) == x`、相対誤差 < 1e-14。`N=8` で素朴な DFT と一致 |
| 2 | ユニタリ性 | 吸収オフで 10000 ステップ、ノルムの相対変化 < 1e-12 |
| 3 | 自由分散関係 | 平面波 `e^(ikx) u₊(k)` の位相が `e^(-i E_k t)` と一致、相対誤差 < 1e-6 |
| 4 | 群速度 | 正分枝波束の `⟨x⟩` の傾きが `k₀/E_k₀` と一致、誤差 < 0.1% |
| 5 | 光速の上限 | `k₀ = 50` でも全時刻で `\|⟨v⟩\| < c` |
| 6 | Zitterbewegung | 50:50 混合の `⟨x⟩` の振動周期が `π/E_k₀` と一致、誤差 < 1% |
| 7 | `m=0` の左右分離 | `m = 0` で `ψ₁` が形を保ったまま `+c`、`ψ₂` が `-c` で進む |
| 8 | Klein の対比 | `V₀ > E + m` の階段で透過率が有意に残る。同じ高さのスカラー階段では指数的に消える |
| 9 | Strang の収束次数 | `Δt` を半分にすると誤差が約 1/4（2 次収束） |
| 10 | 分枝スピノルの数値安定性 | `m = 0` かつ `k < 0` を含む全格子で `u₊`, `u₋` が NaN を含まない |

役割の切り分け:

- 項目 1, 2, 9, 10 — 実装が正しいことの中核
- 項目 3〜7 — 物理が正しいことの中核
- 項目 8 — 教材として成立していることの中核

項目 9 は他と性質が違う。1〜8 は「値が合っているか」を見るが、9 は「誤差の減り方が理論通りか」を見る。
実装バグの多くは値をわずかにずらすだけで閾値テストをすり抜けるが、収束次数は壊れると
2 → 1 のように明確に落ちるため感度が高い。

## 10. 決定事項の記録

| 決定 | 理由 | 却下した案 |
|---|---|---|
| 独立した軽量ビューアとする | `requirements.md` v1.2 は可聴化・学習シナリオを含む大規模アプリで、規模が合わない | v0.1 骨格として作る／物理だけ継承する |
| 実装スタックは参照実装から継承しない | 2026-08-31 のユーザー指示（姉妹プロジェクトの慣習を踏襲しない）が有効。寄せるのは UI レイアウトと操作体系のみ | 単一 HTML ファイル |
| Weyl 表現 | 運動項が成分対角になり分割解法が単純になる。カレントの形も直感的 | Dirac 表現 |
| FFT split-step | 全 `k` で分散関係が連続極限と厳密一致する。運動量空間の表示と分枝射影が副産物として無料で出る | 厳密シフト移流（量子ウォーク型）／密行列 DST |
| 密行列 DST は不可 | 参照実装の sin 基底は `∂²/∂x²` の固有関数だから機能する。Dirac の運動項は 1 階微分で `sin → cos` に写るため sin 基底で閉じない | — |
| ES モジュール分割 + ローカルサーバ | 1500 行前後を 1 ファイルに収めると数値コアの単体検証が困難。ビルド工程は持たない | 単一 HTML（`file://` 起動可）／TypeScript + Vite |
| 吸収は実数マスク窓 | 単純で、質量ゼロでの推奨逆転（電磁型が無反射・スカラー型が全反射）の罠を踏まない | 複素吸収ポテンシャル／実質量ランプ |
| 平滑化は `k` 空間ガウシアン畳み込み | FFT を再利用でき追加コードがほぼ不要。数値精度も改善する | 移動平均／Savitzky-Golay |

厳密シフト移流（案 A）は光円錐が厳密に傾き `c` になる点で魅力があったが、格子分散のぶん
Zitterbewegung 振動数が高 `k` でずれること、分枝射影のたびに別途 FFT が必要になり
`O(N)` の利点が消えることから採用しなかった。将来の比較実装としては価値がある。
